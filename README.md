AZure AI is an an AI learning assistant that students who find it hard to understand AZure Microsoft, get assisted in local languages. There is screen one where Kiswahili, Dinka, Arabi-Juba, & Amharic are. 
A student can choose one of the four languages and proceed to the topic of the choice.
A student who is not familiar with the four languages mentioned-above can go to screen 2 which is below the screen 1. where English and French are. He/she would choose any of the two languages and proceed to the topic of his/her choice.
There is also a reminder button where a student chooses his/her study time and day.
the reminder would be able to remind him/her whenever it is studies' time. This has been made like this to help students not to missed their scheduled days and time for studies.
The app is access by first creating an account with email. The information is then kept in the database such that the student would only be logging it, not to create an account any more.
All the students with account are authorised to use it as long as someone without an account can't access it.
